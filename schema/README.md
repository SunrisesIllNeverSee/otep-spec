# schema/ (SUPERSEDED)

> **⚠️ SUPERSEDED:** This directory contains the original `sigrank/0.1-draft`
> JSON Schema (`sigrank-operator-record-v0.1.schema.json`). It has been
> superseded by the TTEOP (Token Telemetry Evaluation Operator Protocol) specification.
>
> The authoritative TTEOP schemas are in [`../schemas/`](../schemas/):
> - `telemetry-envelope-v0.1.schema.json` — canonical telemetry envelope
> - `conformance-report-v0.1.schema.json` — conformance report format
>
> This legacy schema is retained for backward compatibility with existing
> consumers of the `sigrank/0.1-draft` record format. The TTEOP protocol
> version string `tteop/0.1-draft` is the current normative version; the
> legacy `sigrank/0.1-draft` string is accepted as a backward-compatible
> alias.
>
> Do not use this schema for new TTEOP-conformant implementations.
