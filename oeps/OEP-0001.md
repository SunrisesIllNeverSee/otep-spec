# OEP-0001: Protocol Name and Versioning

**Status:** Draft — bootstrap ratification pending
**Type:** Process
**Created:** 2026-08-28
**Author:** DREP1 (interim Lead Maintainer)

## Summary

Proposes "OTEP" (Operator Token Efficiency Protocol) as the provisional protocol name, replacing the product-associated "SigRank Standard" in normative documents. Establishes the version string format and legacy alias policy. The name is used provisionally pending founder ratification and trademark clearance.

## Motivation

The current specification is named "SigRank Standard," which is a product name. For vendor-neutral adoption, the protocol needs a name that is not associated with any single product. The "ASCII moment for AI measurement" positioning is effective for marketing but should not be the formal name.

## Specification

1. The protocol name is **OTEP** (Operator Token Efficiency Protocol), used as a **provisional draft name** pending founder ratification (UD-1) and trademark clearance (UD-9).
2. The spec version string format is `otep/<major>.<minor>-<status>`.
3. The legacy version string `sigrank/0.1-draft` MUST be accepted as a backward-compatible alias for `otep/0.1-draft`.
4. The metric spec version format is `otep-metrics/<major>.<minor>-<status>`.
5. The conformance report version format is `otep-conformance/<major>.<minor>-<status>`.
6. "OTEP" should be used in all normative documents. "SigRank Standard" may be used in product documentation as a legacy reference.
7. No claim of trademark clearance is made. The name may change if trademark conflicts are discovered during legal review.

## Rationale

- "Operator" centers the human, not the tool or model
- "Token Efficiency" describes what is measured without overclaiming
- "Protocol" signals interoperability
- Pronounceable as "oh-tep"
- No formal trademark search has been conducted. A preliminary search identified no obvious conflicts, but this is not a substitute for legal clearance.

## Backward Compatibility

The legacy alias `sigrank/0.1-draft` is accepted by all consumers. No existing implementation breaks.

## Conformance Impact

Conformance claims transition from "SigRank Compatible" to "OTEP Conformant." Both labels are valid during the transition period. Per SRP-CONF-004, "OTEP Conformant" is reserved until third-party independent validation.

## Bootstrap Ratification

This OEP is treated as a **bootstrap ratification** requiring a recorded founder decision. The naming change has already been implemented across the repository (spec, schema, runner, integrations). Ratification formalizes the decision retroactively without rewriting published history.

**Required founder decisions (recorded in `UNRESOLVED-DECISIONS.md`):**

1. **[REQUIRES FOUNDER DECISION — UD-1]** Is "OTEP" the approved name? If yes, record the decision and advance this OEP to `Accepted`. If no, open a replacement OEP with the new name.
2. **[REQUIRES LEGAL REVIEW — UD-9]** Is the trademark available for registration? This does not block the name from use as a provisional draft name, but blocks trademark filing and certification badge issuance.

Until these decisions are recorded, the name "OTEP" is used provisionally and may be changed.
